# papers/ — 직접 넣는 논문 본문

초록에 결론이 없고 PMC 전문도 없는(유료 저널) 논문은 여기에 본문을 넣어두면 봇이 읽는다.
**PDF 를 그대로 넣으면 된다.** 텍스트로 변환할 필요 없다.

## 이름 짓기

- `papers/38626029.pdf` 처럼 **PMID** 로 지으면 가장 확실하다.
- 이름이 달라도 된다. 출판사가 준 `RSSN_21_2341903.pdf` 같은 이름 그대로 넣어도,
  파일 안의 **DOI** 를 읽어 어느 논문인지 알아낸다.
  (출판사 PDF 에는 보통 PMID 가 안 찍혀 있어서, 내용 대조는 DOI 로 된다.)
- `.txt` 도 된다. 스캔본처럼 글자가 안 뽑히는 PDF 일 때만 그렇게 하면 된다.

## 넣으면 무슨 일이 생기나

`papers/` 에 파일이 push 되면 `redraft` 워크플로가 돌아서

1. 그 논문으로 쓴 대기 초안을 찾아 **본문 근거로 다시 쓰고**
2. 카드를 **다시 그리고**
3. 시트의 훅·답·근거를 **갱신한다** (`초록만` → `직접 넣음`)

id·승인 여부·**쿠팡 링크는 그대로 유지된다.**

## 확인

```bash
python bot/fulltext.py <PMID> <DOI>    # 이 논문 본문을 찾는지, 발췌가 어떻게 나오는지
```
